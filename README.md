# 排列五 V4.1 手動導入版

- 僅分析萬、千、百、十位。
- 每個位置預設候選排除 3 個數字。
- 手動匯入 JSON / CSV，不使用官方 API、自動抓取腳本或 GitHub Actions。
- 每個位置獨立比較平滑頻率、時間衰減、近期/長期收縮混合與趨勢收縮模型。
- 模型選擇以歷史逐期排除命中率為主，對數損失作平手參考。
- 較新保留段逐期驗證；啟用條件為至少 100 次測試且 95% Wilson 下界高於相同排除數量的隨機基準。
- 若不符合條件，系統顯示暫不建議杀号。

## 導入格式

JSON 可使用 `{ "draws": [{"issue":"期號", "date":"YYYY-MM-DD", "number":"01234"}] }`；CSV 使用 `期號,日期,號碼`。號碼必須是保留前導零的五位字串。

## 注意

不同數據集可能產生相同杀号，因為模型輸出取決於數字的相對排序，不是每次導入都必須改變。不得為製造差異而加入隨機杀号。歷史回測不能保證未來準確率。
