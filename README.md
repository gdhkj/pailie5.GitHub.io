# 排列五 V5.1（AI雙引擎初版）

## 本版內容
- 保留 V4.1 的手動 JSON/CSV 導入、前導零校驗、資料指紋、資料本機保存、匯出、還原、四位置頻率分析、逐期樣本外回測及保守判定。
- 新增統計引擎與 AI 特徵融合引擎雙候選結果，兩者獨立計算。
- 每個位置獨立設定排除數量 1–9，預設3。
- 新增可選本機 Qwen2.5-0.5B 語言模型：WebLLM + WebGPU。首次載入需要網絡；模型下載後由瀏覽器快取管理。支援情況依設備、瀏覽器和可用記憶體而定。
- PWA Service Worker 快取網站外殼及內建數據，提供離線頁面功能。
- 沒有官方 API、自動同步、收注或派彩功能。

## 重要技術說明
1. AI 特徵融合引擎是可解釋、可重複的本機特徵評分器，不是已訓練並證明有效的排列五預測模型。
2. Qwen 語言模型只負責獨立提出實驗性候選及審核說明；它的候選未經逐期回測，不會覆蓋正式雙引擎結果。
3. WebLLM 的 Qwen2.5-0.5B 模型需 WebGPU。若 iPhone 瀏覽器不支援或記憶體不足，模型載入會失敗，但其餘功能仍可使用。
4. PWA 可快取網站程式與數據；瀏覽器可能清理網站快取，因此不能保證模型永久離線保存。第一次下載模型及程式庫需要網絡。
5. 回測每期只使用此前訓練窗口資料，基準依各位置 K/10 計算。98.75% Wilson 下界及至少100次測試只是保守觀察門檻，不是預測優勢證明。
6. 開獎數據來源欄位由匯入檔案提供，軟件不會自行驗證每一期是否確為官方原始公告。

## 部署到 GitHub Pages
1. 先下載並解壓 ZIP。
2. 將 ZIP 內 `index.html`、`manifest.webmanifest`、`sw.js`、`README.md` 和 `data` 資料夾上傳到原 repository 根目錄。
3. 覆蓋舊 `index.html`；不要刪除 `data/draws.json`，可選擇覆蓋成套件附帶的500期資料。
4. Repository → Settings → Pages，確認 `main` / `/(root)`。
5. 等待部署完成後，重新打開網站。若仍是舊版，關閉舊分頁再開，或清除網站快取。
