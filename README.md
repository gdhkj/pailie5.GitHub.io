# 排列五 V6.1 GitHub Pages 部署包

## 部署
1. 解壓 ZIP。
2. 將 `index.html`、`draws-all.json`、`data/` 資料夾直接放到 GitHub repository 的根目錄（不要再包一層資料夾）。
3. Commit 到 `main` 分支；GitHub Pages 選擇 `main` / root。
4. 開啟 Pages 網址，首次載入會內嵌完整歷史，不需要手動導入。

## 主要功能
- 內嵌 7,780 期歷史（04001 至 26305），只分析萬、千、百、十位。
- 手動 JSON/CSV 導入、按期號合併、重複衝突檢查、歷史快照與 JSON 備份。
- 智能自動／固定數量模式；每位置可排除 1–9 碼。
- 最多 1,200 期逐期 walk-forward 保留測試；每次只使用該期之前資料。
- 每位置至少 1,000 次測試，使用 z=2.5 Wilson 下界；可匯出逐期 CSV（含候選、實際結果、預測概率）。
- 回測不會覆蓋固定模式手動選號；儲存使用 IndexedDB 並提供 localStorage 備援。

## 注意
這是統計研究工具，不可能保證彩票號碼不會開出。公平隨機開獎下，歷史頻率、間隔或轉移不會創造可靠預測優勢。V6.1 不自動連接官方 API。瀏覽器儲存容量仍由裝置管理，並非真正無限；請定期匯出備份。
