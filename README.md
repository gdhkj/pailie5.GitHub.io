# 排列五 V4.1（手動資料版）

## 部署到 GitHub Pages
1. 解壓縮此 ZIP。
2. 將資料夾內的 `index.html`、`data/` 資料夾及 `README.md` 上傳到 GitHub repository 的根目錄（與原本網站檔案相同位置）。
3. 若 GitHub 詢問是否覆蓋 `index.html`，選擇覆蓋；`data/draws.json` 是資料副本，網站也內嵌這份初始資料，因此可直接運行。
4. Repository → Settings → Pages，確認部署來源為 `Deploy from a branch`、`main`、`/(root)`，儲存。
5. 等待 Pages 部署完成後，手機重新開啟網站；若仍看到舊版，使用瀏覽器重新整理或清除該網站快取。

## 功能
- 僅分析萬、千、百、十位，排除個位。
- JSON / CSV 手動匯入；號碼必須是五位字串，保留前導零。CSV 標題需有 `number`，可選 `issue`、`date`。
- 每位置可選杀号數 1–9，預設 3；分析窗口 30 / 60 / 100 / 300 / 全部。
- 資料保存於本機瀏覽器 localStorage，顯示 SHA-256 指紋、期數、最新期號和日期。
- 逐期樣本外回測：每期預測只使用之前資料，固定窗口，不依回測結果挑最佳窗口。
- 同杀号數隨機基準為 k/10；逐位置以至少 100 次測試、98.75% Wilson 下界高於隨機基準作保守觀察門檻。
- 未通過門檻時顯示「暫不建議杀号」。低頻數字仍會顯示，但明確標為描述統計。

## 注意
本工具不是預測保證。若開獎獨立且公平，歷史頻率不會可靠地預知下一期。資料來源欄位由匯入檔提供，軟件不會自動驗證官方性。沒有 API、自動同步或後台服務。
