## V5.4 修正
1. 逐期回測完成後，同步更新「模型與樣本外驗證」頁面，不再出現回測有結果但驗證頁仍要求導入資料的狀態矛盾。
2. 四個位置各自統計測試次數、命中數、命中率、95% Wilson 下界及隨機基準。
3. 訓練最少期數與每位置最低 100 次有效測試門檻分開說明。
4. 只有每位置至少 100 次，且 95% Wilson 下界高於排除 k 碼的理論隨機基準 k/10，才標示通過；否則暫不建議杀号。
5. 回測逐期只使用當期之前的歷史資料。

## GitHub Pages 部署
1. 備份 GitHub 專案目前的 `index.html`。
2. 將本版 `index.html` 上傳到 repository 根目錄，選擇覆蓋同名檔案。
3. Commit changes。GitHub Pages 若使用 main 分支根目錄，通常稍等部署完成後刷新網站即可。
4. 手機 Safari 若仍顯示舊版，關閉舊分頁後重新開啟，或清除該網站快取。

本版不會自動拉取官方開獎資料；新期數仍可透過網站手動匯入。歷史回測僅是歷史統計，不能保證未來開獎或穩定提高命中率。
