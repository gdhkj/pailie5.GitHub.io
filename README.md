# 排列五 V5.6｜下一期杀号排除分析版

## 核心定義
「杀号排除」是以最新一期已開出的號碼為基準，分析截至該期的完整歷史資料，分別估算下一期萬、千、百、十位各數字的條件分布，將模型估計機率最低的 k 個數字列為下一期候選排除。候選只代表模型相對低估，不代表絕不可能開出。個位不參與分析。

## 歷史資料
- 內嵌 7,780 期，04001（2004-11-14）至 26305（2026-11-15）。
- 最新一期：26305，號碼 26081。
- 五位號碼以字串保存，保留前導零。

## 模型與回測
- 四個位置分開建模與輸出候選。
- 候選依多窗口頻率、時間衰減、近期變化、間隔、相鄰期轉移及 1 至 3 階連續條件轉移集成後的估計機率排序，取最低 k 碼。
- k 可選 1 至 9。
- 逐期回測只使用目標期之前的資料；排除成功指實際開獎數字不在候選排除集合內。
- 每個位置獨立比較其排除成功率與隨機基準（1-k/10），並顯示 Wilson 下界。未通過時仍展示候選作研究參考，但不標記為已驗證建議。
- 回測不是對未來開獎的保證；公平隨機機制下歷史數據不會使某號碼成為不可能。

## 部署
1. 備份 GitHub Pages 根目錄原有 `index.html`。
2. 將本資料夾的 `index.html` 上傳到 repository 根目錄並覆蓋。
3. Commit changes，等待 GitHub Pages 更新。
4. 手機 Safari 若顯示舊版，關閉舊分頁再重新開啟。

此版本不會自動連接官方 API；新增開獎資料仍需手動匯入。`draws-all.json` 與 `data/draws.json` 是獨立備份，網站本身已內嵌完整歷史資料。
